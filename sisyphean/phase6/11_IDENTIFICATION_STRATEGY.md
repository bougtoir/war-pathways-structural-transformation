# 11 — Identification Strategy (Gate 7)

## Primary B-direct design: occupation extraction π∞ case series

- Treatment: coercive occupation/annexation episode with documented
  administrative control.
- Time zero: effective control date (documentary, not onset of war).
- Outcome: per-occupation-year net extraction A − C(r), sign only.
- Comparison: cross-case asset-mix contrast — cases matched on scale/
  era differ in whether π∞ > 0 by predicted w_phys dominance.
- Selection: occupying powers select targets ex ante — expected
  direction is *toward* appropriable targets, so a null within selected
  cases is informative against naïve claims; stated honestly.
- Interference: third-party sponsors and sanctions contaminate both
  A and C — coded as covariates.
- Pre-trends/comparability: no treated-control panel exists; inference
  is cross-case descriptive, never causal.
- Immortal-time/early-ending conflicts: no exclusion on post-treatment
  duration; short occupations enter as censored cases with sign-coded
  partial extraction (bias direction documented).

## Result class attainable

**Descriptive/associational only.** No instrument for asset mix exists;
any sign-pattern table is evidence of consistency, not causation.

## Appendix (secondary, indirect — different mechanism)

The Phase-4/5 sponsor-externality duration design (SIPRI×UCDP) is an
A-level test of sponsor channels — explicitly *not* a test of B and
labeled as such. It is not the primary design.

occupations (see 10_CASE_FEASIBILITY_MATRIX.xlsx): coding 8–12 cases to
the doc-08 components is feasible but is original archival work — not
