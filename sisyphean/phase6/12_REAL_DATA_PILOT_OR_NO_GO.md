# 12 — Real-Data Pilot: EMPIRICAL NO-GO (B-direct)

## Verdict

**EMPIRICAL NO-GO for the B-level test in this session.** No existing
public dataset measures A (appropriated value) or the asset-mix
composition needed for the level-condition test; executing a "pilot"
on conflict duration would substitute the convenient A-level proxy the
prompt explicitly forbids.

## Why not executed

- The B-direct estimand (sign of π∞ by asset mix) requires original
  archival coding — protocol specified (09_ORIGINAL_CODING_PROTOCOL.xlsx),
  a bounded 8–12-case series is feasible but is a data-collection
  project, not a pilot of existing data.
- Public panels (UCDP, SIPRI, WDI, V-Dem) cover duration, flows,
  outcomes — none code extraction channels (fiscal transfers, forced
  trade balances, enterprise control) needed for numerator A.

## Minimum-data acquisition plan (precise)

1. Case sampling: all post-1945 occupation/annexation episodes in the
   feasibility matrix rated ≥3 on documentary completeness.
2. Per case: code V_pre (3 pre-occupation years, WDI/ Maddison),
   V_post (annual under occupation), A components by channel,
   C (administration/suppression budgets where records exist), h
   (displacement, mortality).
3. Deliverable of that project: sign(π∞) per case + asset-mix coding →
   one cross-case consistency table vs the level prediction.
4. Record all retrievals per the persist rule: raw snapshots + ledger.

## What was NOT done (by rule)

No simulated/pretend observations; no relabeling of duration data as
appropriability; no p-values from a proxy study presented as a B test.
