## Two rival mechanisms reproduced at comparable calibration

**Rival A — static contest (Grossman-Kim / Hirshleifer type).**
Appropriation A = r·V — contest success linear in effort; no state, no
consent. At matched (V̄, c1, c2): optimal r* = (V̄−c1)/(2c2) = 1.7>r_max
→ interior at r_max, π = 0.60. Prediction: coercion always pays when
V̄ > c1 + c2r; no dependence on asset composition. **Observationally
distinguishable**: our model predicts sign reversal across w_phys; the
static contest does not.

**Rival B — pure hold-up (KCA type).** Appropriable quasi-rent set
exogenously; once sunk, coercer extracts the full rent. Prediction:
extraction complete regardless of cooperation — no L channel at all.
Distinguishable only if withdrawal observable.

## Genuinely discriminating prediction (the only one)

Given two conflicts with identical (V̄, c1, c2, r) but different asset
mixes, the level-condition model predicts **different continuation/
abandonment behavior for the coercer**; all static rivals predict the
same. Where behavior can be observed (occupations with coded asset
mix), this is testable — the original-coding protocol (doc 09) exists
exactly to make it measurable.

## Honest equivalences conceded

- vs bargaining/sanctions duration models: on conflict *duration* our
  model adds nothing discriminating (Phase-4 result, intact).
- vs commercial peace: aggregate correlation is a different estimand —
  neither confirms nor refutes the level model.

## Verdict

The model is **mostly a useful synthesis**; the single novel formal
object is the asset-mix-conditioned level condition, and it carries
exactly one discriminating prediction.
