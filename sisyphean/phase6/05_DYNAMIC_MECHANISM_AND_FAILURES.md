# 05 — Dynamic Mechanism and Failures (Gate 4)

## Distinct event definitions (kept separate everywhere)

- **initiation**: first transition coercion=false→true (r>0).
- **persistence**: coercion=true span (spell).
- **cessation**: coercion=false after a spell, by exit type
  {unprofitable, K-depletion, cap}.
- **displacement**: violence relocated to proxy_left state — counted
  separately, never as cessation success.
- **recurrence**: new onset after cessation.

## Endogenous value/capacity feedback — what's actually in the model

Initiation changes future attainable value **through the cooperation
state only**: r>0 → dL/dt < 0 (or flat under fear) → V(L) and α(L)
fall during the spell — no imposed negative jump. Feasible coercive
capacity degrades through K burn > ρ (Phase-3/4 mechanism unchanged).

## "Unprofitable" vs "infeasible" — explicitly distinct exits

- unprofitable: π∞(r) < 0 (level condition, Gate 1).
- infeasible: K ≤ K_min (sustainment stock exhausted).
They need not coincide; the model records which fired.

## External sponsorship / substitutes / third-party extraction

Patron replenishment raises ρ above burn → K never depletes (failure);
substitute resources (sub_rate) same effect; third-party extraction not
modeled — flagged as extension, not silently assumed away.

## Non-maximizing aggressors

intrinsic/regime_survival rules ignore π — no level condition binds
them; documented in Phase 5 g8, preserved.

## Outcomes protected

cumulative civilian harm h (never credited to the mechanism),
defensive capacity d ≥ d_min, recovery via L rebound when coercion
stops, reachability of initiation states (barrier B optional).

## Failure map (carried + new)

1. tolerant patrons / substitution → no K exit (Phase 3–5).
2. persistent displacement → violence widened (Phase 4).
3. low-cost coercer + physical assets → π∞ > 0 (Phase 6 counterexample).
4. fear-driven compliance → L does not fall; extraction continues.
5. rule-bound populations keep L above the LVL threshold where
   optimizing ones fall below it — behavior spec alone decides the sign.
