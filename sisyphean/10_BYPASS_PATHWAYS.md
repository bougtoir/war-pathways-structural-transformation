# 10 — Bypass Pathways

The prompt requires each bypass be modeled, not asserted away.

| pathway | implementation | outcome |
|---------|---------------|---------|
| external sponsors | `sponsor` ρ term in dK | **breaks the lever** when unbounded (adversarial_failure: p_K_exit = 0) |
| stockpiles | `S_p0` + `s_release` | delays exit by ≤ S_p0/(b−ρ); bounded unless stockpile enormous |
| import substitution / black markets | folded into `sponsor` net rate | same failure region as sponsors |
| institutional capture | `e_b` error on bureaucratic rule | changes onset frequency, not sustainment — keystone still binds |
| technological adaptation | `spill` channel in m_target | war-facilitating; enlarges feasible set (gate16) |
| proxy conflict | `resist_burn` paid by sponsor instead of own K | not separately parameterized — LIMITATION: a sponsor absorbing burn is equivalent to sponsor↑, already shown to defeat the lever |
| defender capacity | `d` drains attacker K via resist_burn | complement, not bypass: strengthens defender's position safely |

**Summary:** the lever's falsifying region is {ρ ≥ b}: external resourcing
that scales with aggression defeats self-exhaustion. All other pathways are
either absorbed into that condition or shown non-fatal.
