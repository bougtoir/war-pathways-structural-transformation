# 10 — Empirical Identification (Gate 9)

Three designs evaluated; all capped at descriptive/mechanism level.

## Design A — historical occupation case comparison

- Unit: occupation-episode (post-1945 set per feasibility matrix).
- Treatment: documented administrative control.
- Outcome: sign(π∞ = A − C) per episode.
- Estimand: covariation of sign(π∞) with asset mix.
- Counterfactual: none within-case; comparator dyads weak.
- ID assumptions: selection into targets must not correlate with
  unobserved appropriability — implausible; occupiers select the
  appropriable. Result class: **descriptive only**.
- Confounders: occupier selection, era effects, sanction co-occurrence.
- Data: feasibility matrix; 4–5 cases YES, rest partial.
- Feasibility: bounded series possible; causal claims impossible.

## Design B — coercive vs negotiated arrangements

- Unit: sovereignty-transfer / concession episodes (occupied vs
  negotiated cessions — e.g. Hong Kong-type or treaty cases).
- Treatment: coercive vs negotiated mode.
- Outcome: post-transfer extraction relative to pre-transfer potential.
- Estimand: mode effect on realized value.
- Counterfactual: negotiated cases proxy non-coercion — but selection
  into mode is endogenous (weak states get coerced).
- ID: no instrument → **associational at best**.
- Feasibility: cases exist (few); classification contested.

## Design C — asset-composition heterogeneity

- Unit: occupation episodes split by target sector structure.
- Treatment: none — observational contrast on w_phys share.
- Outcome: extraction per year, occupation persistence.
- Estimand: dose-response of extraction on physical share.
- Counterfactual: missing data-generating story; confounds with
  occupier type (industrial occupiers pick industrial targets).
- Result: **descriptive; the discriminating prediction is testable
  only at this level**.

## Summary

| design | descriptive | mechanism evidence | causal |
|---|---|---|---|
| A | yes | pattern-level only | no |
| B | yes | weak | no |
| C | yes | the only place the novel prediction bites | no |

No defensible causal identification exists for the B-level estimand —
stated, not circumvented.
