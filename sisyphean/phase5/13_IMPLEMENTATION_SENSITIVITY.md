# 13 — Implementation Economics (secondary, Gate 9)

No viable stand-alone mechanism was proven, so this is bounded
sensitivity, not a proposal. 1,000 trillion JPY = anchor only.

## Structure

- **Costs**: implementation I (unmeasurable at present), maintenance
  ~2%·I/period, transition/retraining nonzero, financing political.
- **Feasibility separation**: technical feasibility ≠ net social
  benefit ≠ political financing — carried as three distinct verdicts;
  none currently evaluates positive.
- **Anchor**: at the 1000T-JPY anchor every Phase-4 cell was
  net-negative; nothing in Phase 5 changes that — reported unchanged.
- **Incidence**: payers = current funders; beneficiaries = future
  civilians; losers = war-economy beneficiaries (endogenous
  resistance — free riding and institutional capture noted, unsolved).

## Shared-future vision as optional sensitivity

V (shared futures) treated exactly as Phase-4 Gate 37: optional scalar
modulating coordination cost / willingness to pay, sign unrestricted
(backlash included), never a premise of any theorem or estimate.
No core result depends on V.

## Dual-use conversion (exploratory)

Phase-4 Gate-35 result carried forward unchanged: conversion is
net-positive only at utilization ≳ 0.3 and below the c_conv edge;
double-counting avoided; retraining costs nonzero; spill-back to
military capacity flagged. Disaster response / remote operations /
space-exploration-adjacent capacity listed as candidate reduction of
transition cost — not as proof unemployment vanishes.
