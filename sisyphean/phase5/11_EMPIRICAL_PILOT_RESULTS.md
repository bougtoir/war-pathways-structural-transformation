# 11 — Empirical Pilot: explicit conditional NO-GO

Gate 7 precondition — "only if measurement passes" — is **not met** for
the core construct. Reported as feasibility audit, not fabricated
results.

## What the audit found (09_*.xlsx)

| construct | best public proxy | verdict |
|---|---|---|
| appropriability α | none — no dataset codes capturable share | **not measurable** |
| consent L | V-Dem civil-liberties + labor flows | partial, contested |
| realized value A | GDP/tax records of occupations — sparse, biased to successes | weak |
| sponsor externality | SIPRI TIV + sanctions event dates | **measurable** (Design B only) |
| displacement | UCDP non-state violence | measurable with caveats |

## Consequence

The discriminating-implication test that survives (Design B) tests the
*sponsor channel* — i.e., the A-level war case, not the B-level
appropriability construct. No public data permits a direct test that
consent-dependent value is less capturable. What an original coding
effort would require: post-conquest extraction flows, target asset-mix
coding, collaboration rates — out of scope for a gated theory phase.

## Feasibility verdicts per source (no downloads performed; metadata only)

- UCDP: free research license, dyadic-year, suitable for Design B.
- SIPRI TIV: free register-based download, suitable.
- V-Dem: free, suitable as covariates.
- COW: free, suitable as controls.
- Archigos: leaders; usable for regime-survival robustness.
- OECD TiVA / Comtrade: usable for interdependence covariates, not
  appropriability.

Stopping rule honored: no empirical estimate is reported; nothing is
claimed beyond audit.
