# 03 — Conceptual Taxonomy

Hierarchy: **B (superordinate)** structural obsolescence of coercive
appropriation; **A (subordinate)** war as one coercive instrument.

## Coercion vs. non-coercion — definitions used

| term | definition here | boundary note |
|---|---|---|
| coercion | extracting/control via credibly imposed cost or force | exercise of public authority is NOT coercive merely by being authoritative; enforcement with legitimacy and due process is a different category |
| threat | conditional promise of coercion | cheap vs credible kept distinct |
| extortion | coercion + explicit quid pro quo | subcase |
| conquest | coercion aimed at durable possession | |
| occupation | conquest succeeded administratively | Liberman's domain |
| appropriation | conversion of value to the coercer's use | ≠ possession |
| military defense | resisting coercion, not initiating it | protected throughout |
| legitimate enforcement | authority under consent/legality | excluded from "predatory coercion" |
| nonviolent bargaining | voluntary exchange of claims | the comparator |

## Core distinctions (Gate prompt numbering)

1. V_produced vs A_realized: distinct state variables in model5.
2. possession ≠ usable control ≠ realization: implemented as
   r (possession) × α(...) (usability/realization).
3. destruction ≠ non-transferability: civilian harm is a measured cost
   (h), never credited to the mechanism.
4. appropriability vs peaceful substitutes: model keeps a peaceful
   alternative payoff UA in fires(); feasibility of substitutes is a
   parameter not a claim.
5. actor objectives: coercer/leader/population/sponsor/balancer each
   have own rules.
6. short-run vs long-run: A enters flow payoff; hollow episodes show
   tactical A > 0 with net < 0 over the spell.
7. cessation vs displacement: displacement is a persistent state with
   its own harm channel (Phase 4 convention preserved).
8. incentive vs capability: non-maximizing rules (intrinsic,
   regime_survival) ignore payoff signs — recorded as failures, not
   assumed away.

## What the framework does NOT claim

Reduced appropriable gain does not imply less *destructive capacity* —
a coercer unable to profit can still harm. Failure to appropriate is
not inability to inflict violence.
