# 03 — Novelty Boundary

## Claimed (defensible)

1. **Endogenous replenishment law**: ρ(t) is a state of the model, set by
   sponsor externality tolerance — distinguishing *stock depletion* from
   *law change*. Attrition models deplete stock; sanctions models impose
   exogenous ρ; here ρ responds to the conflict's own externality.
2. **V_G ≠ U_L separation**: attainable efficacy collapses while perceived
   utility may not → *hollow war* as a defined state (V_G < 0.2 while
   war continues). Hollow persistence is measurable and predicted to
   precede cessation — no baseline produces it.
3. **Consent-holder actor mechanism**: objective efficacy derives from
   third-party cooperation withdrawal (two non-maximizing rules), not a
   stipulated payoff decline.

## Not claimed

- New mechanism discovery: every component exists in prior work
  (counterproductive coercion, shifting power, war economies). Novelty
  is formal synthesis + the hollow-war state + falsifying region ρ ≥ burn.
- Onset prevention: barriers delay/filter, never prevent over long
  horizons (P_hit ≈ 1).
- Rationality independence at onset: frequencies remain rule-dependent.
- Universal keystone: no single globally identifiable K for all wars;
  claim is conditional on a causally necessary stock existing.
- Real-world magnitudes: all parameters illustrative.

## Synthesis verdict (Gate 18/26)

The theory is a **synthesis with three new structural elements**
(replenishment-law endogeneity, V_G/U_L split → hollow war, consent-actor
derivation of value collapse). Each element survives a matched-null
comparison (06). If a later literature find formalizes the same triple
jointly, this becomes pure synthesis — flagged, not fatal.
