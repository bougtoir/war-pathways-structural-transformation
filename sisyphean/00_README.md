# The Sisyphean Lever — Gated Theory Revision

Second-phase theory revision of the Structural Transformation of War
Pathways package (parent dir). Provisional hypothesis label only:
*organized war should be hard to initiate, and initiation should
endogenously degrade the conditions sustaining it — without sacrificing
civilian welfare, rights, or legitimate self-defense.*
